# 🛒 Walmart Data Analytics Capstone

This project simulates the role of a Data Analyst at Walmart, transforming raw transactional and operational data into business insights. It covers the end-to-end analytics workflow — from SQL-based data extraction, to business visualization in Power BI, to predictive modeling with Python.

![Main page dashboard](https://github.com/farook8090/wscubetech-capstone-project/blob/287aa3aba38594c6686fbd6a6751f3ac0f98a2c7/Wallmart/Wallmart-01.png)

# 📊 Project Overview

The goal of this project is to analyze Walmart’s operations across multiple regions, focusing on sales performance, customer behavior, seller efficiency, and logistics optimization.
It is divided into three phases:

SQL Analysis – Extract insights on sales revenue, customer loyalty, order behavior, and seller performance.

Power BI Dashboard – Build interactive dashboards for executives to track KPIs and visualize trends.

Python Modeling – Apply predictive and prescriptive analytics for sales forecasting, churn risk, and operational improvements.
